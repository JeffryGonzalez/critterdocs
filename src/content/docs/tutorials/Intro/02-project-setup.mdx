You will need a few things to get started here:

- A Container Runtime (Like Docker Desktop, or Podman, etc.)
- A .NET SDK (Version 9.0 or later)
- A Code Editor (Like Visual Studio, Visual Studio Code, NeoVim, Rider, etc.)
    - I will use Jetbrains Rider in this course, but you can use whatever you like. You can get a free license for Rider for non-commercial use, etc. [See Rider](https://www.jetbrains.com/rider/)

<DoThis label="Get the Starter Code" >


You can download a `zip` file with the starter code for this course from [CoursesSolution_Starter.zip](/tutorials/CoursesSolution_Starter.zip)
</DoThis>

Extract the zip file to a directory of your choice and open it with the editor of your choice.

In the extracted directory, you will find a `docker-compose.yml` file. Use that to start the Critter Stack by running the following command in your terminal:

<DoThis label="Start Docker with a Postgres Database" >
```bash
cd CoursesSolution
docker compose up -d
```
</DoThis>

### The Final Code 
You can also pull down a "final" working copy of this project using the same process as above, but using the following zip file:
[CoursesSolution_Final.zip](/tutorials/CoursesSolution_Final.zip)


In another directory. Make sure you start the container!
