We will put notes and things here for some continuity of how this site will work.

For the content, I'm working roughly from the [Diataxis](https://diataxis.fr/) framework, which is a framework for organizing documentation into four categories: tutorials, how-to guides, explanations, and reference.

### Tutorials

Tutorials are lessons. They are designed to help developers acquire new knowledge. The challenge is to keep them focused and accomplishable. They should be step-by-step. You do not need to explain *everything*. 

Tips:
- Use footnotes for links to additional information (could be in the **Explanations** or **How-To Guides** sections).
- Use code examples to illustrate concepts, and keep them simple and focused. 
- Have "starter" code and a solution available. 
- Video Walkthroughs are a nice addition, but not always required.
- You don't have to necessarily show "best practices", but they should be "good practices" - in other words, leave room for more content and improvement, questions, etc. but prioritize clarity and simplicity.

### How-To Guides

How-to guides are different than tutorials. They are not as *step-by-step* as tutorials, but they are still focused on helping developers accomplish a specific task or solve a problem.

Unlike tutorials, these should be "transferrable" to working projects the developers are building. 

We may want to have a consistent example project that is linked to for these, keeping the example code in line with actual running code.

Examples might be:

- How do I set up testing using XUnit or TUnit?
- How do I rebuild projections?
- How do I do blue/green deployments?

### Deep Dives (Explanations)

I vary from the language of the Diatraxis framework here (they call them "Explanations"), but these are the "deep dives" into concepts, patterns, and practices. They are not necessarily step-by-step, but they should be clear and concise.

We'll have to see how this pans out, because it can be confusing here between things like "References" and "Deep Dives".

These can be text-based, or videos (Links to Youtube or Vimeo). They can also be a combination of both.

Examples might be:

- Event Sourcing "Big Picture" stuff.
- CQRS "Big Picture" stuff.
- Projections, Aggregates, etc.
- Smaller Topics like:
    - What is a "Saga"?
    - What is a "Stream"?
